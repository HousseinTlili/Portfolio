## 🌟 Overview

A modern, high-performance developer portfolio built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Vite**. Features a luxury glassmorphism dark aesthetic inspired by modern AI developer tools, comprehensive multilingual support (English, French, and native RTL Arabic), interactive case studies, and instant CV downloads.

### ✨ Key Features

- 🌐 **Full Multilingual & Native RTL Support**:
  - Seamless toggle between **English**, **Français**, and **العربية**.
  - Custom RTL layout engine with typography anti-crushing rules and BiDi protection for Arabic.
- ⚡ **Ultra-Fast Performance**: Built on Vite with near-instant hot module replacement (HMR) and optimized static asset chunking.
- 🎨 **Luxury Dark UI / UX**:
  - Glassmorphic navigation bar with blurred backdrops.
  - Interactive project detail modals with comprehensive architectural case studies.
  - Responsive timeline for production experience and academic credentials.
- 📄 **Direct Resume Download**: Integrated one-click CV download serving static PDF assets directly from the edge CDN.
- 🔍 **SEO & Social Meta Ready**: OpenGraph preview cards, Twitter summary tags, semantic markup, and custom favicon.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm` or `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/HousseinTlili/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
